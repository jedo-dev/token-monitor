# Корпус Token Monitor

Настольный корпус для Waveshare ESP32-S3-Touch-LCD-4 **Rev4.0**: плоский корпус
из двух половин и отдельная подставка с наклоном 15°. Дисплей надевается на
подставку сдвигом вниз («ласточкин хвост») и так же снимается.

Габариты: корпус 90 × 90 × 20.2 мм, подставка 92 × 78 мм, высота в сборе ~110 мм.

| Файл | Что это |
|---|---|
| `token_monitor_case.scad` | исходник, все размеры параметрами |
| `front.stl` | передняя рамка |
| `back.stl` | задняя крышка с рельсом |
| `stand.stl` | подставка |
| `view_screen.png`, `view_front.png` | как выглядит в сборе |

## Ключевой размер — толщина

**`stack_h = 15.0`** — замер по месту: от лицевой поверхности стекла до самой
выступающей детали сзади (винтовой клеммник). Из него считается вся глубина
корпуса, так что менять достаточно эту одну строку. При 15 мм корпус выходит
20.2 мм толщиной, а втулки под плату — 9 мм.

Стоит также сверить `usb_y = -11.7` — центр USB-C относительно центра платы по
вертикали (вниз — отрицательное). Проём сделан шириной 13 мм, поэтому ошибка в
пару миллиметров не страшна. И толщину стекла `glass_t = 2.2`.

## Печать

| Параметр | Значение |
|---|---|
| Материал | PLA или PETG |
| Слой | 0.2 мм |
| Стенки | 3 периметра |
| Заполнение | 20% (подставка — 35%, чтобы стояла увереннее) |
| Поддержки | только для подставки |

Ориентация на столе:

- **Передняя рамка** — лицевой гранью вниз. Так лицо получается гладким,
  а поддержки не нужны.
- **Задняя крышка** — рельсом вверх (плоской стороной на стол), без поддержек.
- **Подставка** — основанием вниз, включить поддержки: наклонная опора нависает.

## Сборка

1. Уложить стекло дисплея в карман передней рамки лицом вниз.
2. Сверху положить плату разъёмами к вырезу USB-C (он на правом торце,
   если смотреть на экран).
3. Накрыть задней крышкой: четыре втулки внутри крышки войдут в монтажные
   отверстия платы и прижмут её к дисплею.
4. Стянуть 4 винтами **M3×12** (саморезы по пластику) через углы крышки.
5. Надеть на подставку сверху вниз, пока рельс не сядет на упор.

## Правки размеров

Все размеры вынесены в начало `.scad`. Меняете значение, затем:

```bash
openscad -o back.stl -D "part=\"back\"" token_monitor_case.scad
```

Либо открыть файл в OpenSCAD, поправить, F6, `File > Export > Export as STL`.

Полезные параметры: `tilt` — угол наклона, `clr` — зазор вокруг стекла,
`rail_slack` — насколько туго дисплей садится на подставку (при тугой посадке
увеличьте на 0.1 мм), `wall` — толщина стенок.
