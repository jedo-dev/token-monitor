# Развёртывание

Установка отправщика на ПК и ноутбук, схема работы и разбор проблем — в
[основном README](../README.md#установка-на-новую-машину-пк-ноутбук).

- `install-pusher-autostart.ps1` — автозапуск отправщика на Windows.
- `token-broker.service` — systemd-юнит запасного брокера `agent/token_broker.py`
  на случай, если magic-qube недоступен. В текущей схеме не используется.
